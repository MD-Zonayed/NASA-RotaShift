# RotaShift current status

**Status:** hackathon prototype / source-and-data package assembled from the three team-uploaded ZIP archives.

**What is actually in the repo:** a Streamlit app, a 13-crop rule-based rotation scorer, NASA POWER live API integration, actual SMAP and MODIS Earth Engine raw exports, processed NDVI/SMAP context series, BARC/BRRI references, Farmbot photos, and one seven-slide demo.

**What is not complete:** plot-accurate GPS; real Farmbot sensor log; real soil-moisture calibration; HLS export outputs; full rice BARC yield-group coverage; verified disease thresholds; field/yield validation; complete public GitHub/hosted demo links; final teammate roster names.

See `docs/DATA_STATUS.md` and `docs/PUBLIC_RELEASE_CHECKLIST.md`.
