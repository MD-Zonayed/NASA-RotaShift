# Licence status — review before adding a licence

This repository is packaged for public project review, but no blanket open-source licence has been added. The source archive notes that a Streamlit dashboard helper was adapted from another author's open project and that its licence needs checking. The exact upstream repository/licence was not included in the uploaded files.

Before adding MIT, Apache-2.0, or another licence, confirm: (1) ownership of all source code; (2) the upstream helper's licence and required attribution; (3) licences for Roboflow datasets and model assets; and (4) rights to redistribute all images/media. NASA/USGS data products may have public reuse terms, but those terms do not automatically license the team's code or every third-party asset.
